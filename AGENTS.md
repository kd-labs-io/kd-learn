
## Rules

- Chat: reply in the conversation's language.
- Code, names, comments: English.
- `plan/**`, `proble/**` : using language in the file.
- MVP, solo developer: when a PR's CI is green and you are confident in the change, merge it into `main` without asking.

## Directories

- `probe/`: brainstorming only (ideas, Q&A, superseded drafts). Never act on it directly.
- `plan/`: actionable plans, split by topic; start at `plan/README.md` (index: which file to read for what). This is the source of truth for what to build. If `probe/` and `plan/` disagree, `plan/` wins.

## Code notes

- Astryx (UI) guidance lives in `apps/web/AGENTS.md`; it also applies to `packages/ui`.
- i18n strings: edit `packages/i18n/messages/`. Never edit `packages/i18n/src/paraglide/` (generated by Paraglide).
